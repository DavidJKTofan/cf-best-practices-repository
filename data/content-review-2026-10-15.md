### Four additions

- **Handle Reported Security Detection Failures:** `cf.appsec.request.failed_detections` was introduced on [2026-10-09](https://developers.cloudflare.com/changelog/post/2026-10-09-failed-detections/). An empty array means no failures were reported, not that every detector ran. Available on all plans without granting underlying product entitlement.
- **Require Valid JWTs Before Trusting API Identity:** use `cf.api_gateway.tokens.valid` in WAF rules; do not confuse token presence, token validity, application authorization, or the inverted semantics of legacy token policies.
- **Verify Origin TLS with Full (Strict):** verify server identity as well as encrypting the origin connection. [Requirements](https://developers.cloudflare.com/ssl/origin-configuration/ssl-modes/full-strict/).
- **Audit Security Bypasses and Narrow Managed Rule Exceptions:** inspect IP Access Allow entries, Skip scope, and account/zone coverage. [Interoperability](https://developers.cloudflare.com/waf/feature-interoperability/).
