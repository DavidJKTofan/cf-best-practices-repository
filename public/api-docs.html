Reference / Public read API

Read once. Retrieve anywhere.

Anonymous access to the same sourced practices in HTML, JSON, and Markdown. No API key, account, or JavaScript required.

Content formats

Send Accept: text/markdown to / or /practices/{id}. Browsers receive HTML by default; negotiated responses send Vary: Accept. Explicit Markdown URLs are /index.md and /practices/{id}.md.

Start with /llms.txt for links, or /llms-full.txt for all practice details. Cite canonical /practices/{id} URLs and their linked sources.

JSON endpoints

  • GET /api/practices — all practices and configuration details.
  • GET /api/categories — category IDs and names.
  • GET /api/features — feature IDs, names, and documentation URLs.

Responses are {"success": true, "data": [...], "count": 123}. The count reflects the returned records. There is no pagination.

Filters

/api/practices accepts search (literal substring, up to 200 characters), categoryId, featureId, area (Security, Performance, Reliability, General), level (Mandatory, Recommended, Optional, Situational), and impact (High, Medium, Low). Filters combine with AND. Unknown IDs return no records; invalid filter values are ignored. 

curl 'https://db.automatic-demo.com/api/practices?search=WAF&area=Security'
curl -H 'Accept: text/markdown' https://db.automatic-demo.com/

Caching, errors, and authentication

GET, HEAD, and OPTIONS are supported for public reads. Cross-origin reads are allowed. Practice responses may be cached by clients for 60 seconds; taxonomy responses for 300 seconds. The edge cache is invalidated after dashboard writes.

Errors use appropriate HTTP status codes. JSON API errors return {"success": false, "error": "..."}. A 429 includes Retry-After: 60; respect it and reuse cached results. Missing practice pages return 404, and unavailable content returns 503.

Public reads need no authentication. Writes exist only under the Access-protected dashboard; see authentication guidance.

Discovery and responsible use

Use the OpenAPI schema, API catalog, agent skills index, and capability manifest. Search indexing and AI answer retrieval are permitted; AI training is not.
