Reference / Public read API

Read once. Retrieve anywhere.

Anonymous access to the same sourced practices in HTML, JSON, and Markdown. No API key, account, or JavaScript required.

Content formats

Send Accept: text/markdown to / or /practices/{id}. Browsers receive HTML by default; negotiated responses send Vary: Accept. Explicit Markdown URLs are /index.md and /practices/{id}.md.

Start with /llms.txt for links, or /llms-full.txt for all practice details. Cite canonical /practices/{id} URLs and their linked sources.

JSON endpoints

  • GET /api/practices — all practices and configuration details.
  • GET /api/categories — category IDs and names.
  • GET /api/features — feature IDs, names, and documentation URLs.

v1 responses are {"success": true, "data": [...], "count": 123}. The count reflects the returned records. v1 has no pagination.

The optional expression field contains an explicitly authored Rules expression. The existing expressions_configuration_details field retains setup guidance, actions, thresholds, commands, and counting expressions; it is not necessarily paste-ready. Adapt examples and verify prerequisites before use.

Filters

/api/practices accepts search (literal substring, ASCII case-insensitive, up to 200 UTF-16 code units), categoryId, featureId, area (Security, Performance, Reliability, General), level (Mandatory, Recommended, Optional, Situational), and impact (High, Medium, Low). Filters combine with AND. Unknown IDs return no records; invalid filter values are ignored.

Search removes NULs and trims input before truncation. Non-ASCII case is exact; percent, underscore and backslash are literal characters, not wildcards. 

curl 'https://db.automatic-demo.com/api/practices?search=WAF&area=Security'
curl -H 'Accept: text/markdown' https://db.automatic-demo.com/

Versioned catalog reads

  • GET /api/v2/entries — published summaries without bodies or sources.
  • GET /api/v2/entries/{id} — one complete published JSON detail; unpublished IDs return 404.
  • GET /api/v2/facets — populated type/family/product/outcome counts.

AND filters are q (literal title/summary substring, ASCII case-insensitive, up to 200 Unicode code points), canonical family, product, outcome slugs, and type. This is not full-body or relevance-ranked search. Facets apply all filters together; empty/draft-only taxonomy is absent.

Listings return {success, data, count, total, page, pageSize, pages, query, links}. Default page size is 20 (maximum 50); page starts at 1 (maximum 10000). Invalid/zero page values use defaults; positive values above bounds are clamped. links contains relative self, next, and previous URLs. Out-of-range pages are empty with an accurate total; next stops at page 10000. Sort by title (default) or newest, then numeric ID ascending. Pages can shift between requests after a write.

Unknown/default parameters are removed before caching; first duplicate wins. Invalid filters are ignored; unknown valid slugs match nothing. Legacy imports use schemaVersion: 0, type: legacy-practice, and an unchanged v1 body, without invented taxonomy or fact-verification dates. Typed content uses schemaVersion: 1 and a published revision. Operational runbooks remain type: implementation-guide, with body.variant: operational-runbook on detail reads. They separate symptoms, read-only diagnosis, approved changes, recovery, success criteria and rollback. There is no separate runbook type filter; instructions are not authorization to make changes. Use canonicalPath for HTML citations and detailPath for JSON. Published native entries also support Markdown negotiation and explicit .md URLs. Full exports stream all current published entries; v1 remains legacy-only. Browse URL-based search and populated /families/{slug} hubs without JavaScript; append .md to either listing path for the same effective result page. No query flag exposes drafts, and there are no v2 write routes. See the v2 schema or complete Markdown contract.

Summaries and details include lifecycle: state is active, deprecated, or superseded. Retired guidance remains readable at its stable URL with a public reason; supersededBy identifies its replacement. Check the replacement's current status and applicability before use, and do not present retired examples as current recommendations. Active status alone is not proof of freshness or entitlement.

Caching, errors, and authentication

GET, HEAD, and OPTIONS are supported for public reads. Cross-origin reads are allowed. Practice responses may be cached by clients for 60 seconds; v1 taxonomy responses for 300 seconds. v2 facets share the 60-second content TTL and practices purge tag. Dashboard writes attempt a shared purge; browser caches and immediate global visibility are not guaranteed.

Errors use appropriate HTTP status codes. JSON API errors return {"success": false, "error": "..."}. A 429 includes Retry-After: 60; respect it and reuse cached results. Missing practice pages return 404, and unavailable content returns 503.

Public reads need no authentication. Writes exist only under the Access-protected dashboard; see authentication guidance. The local, not-yet-deployed typed workflow has a separate protected editorial schema and requires private role grants in addition to login. It is not part of the public read tools.

Discovery and responsible use

Use the OpenAPI schema, API catalog, agent skills index, and capability manifest. Search indexing and AI answer retrieval are permitted; AI training is not.
