## Root cause and repair

The existing production build trigger had an empty build command and plain `npx wrangler deploy`. Wrangler tried bundling `src/astro-worker.ts` directly and could not resolve Astro virtual imports. This was a missing framework build step, not missing dependency aliases.

Changed only the trigger's two command fields, preserving its production branch, repository, token, root, caching and filters:

- Build: `npm run build`
- Deploy: `npx wrangler deploy --config dist/server/wrangler.json`

The existing `npm run deploy` already uses the correct build/generated-config sequence. No application-source workaround was needed. Added the explicit Workers Builds recipe to README so a new Git integration is not left on the incompatible default.
